Source: User-provided Rat_Sightings.xlsx (NYC rat-sighting complaints). Dates stored as text were parsed as day/month/year. Closed percentage uses cases marked “Closed”; mean resolution time uses nonnegative closed-minus-created intervals up to ten years. Regression is a descriptive linear fit, not a seasonal predictive model. ZIP locations are report-coordinate averages; borders are approximated from source point locations, not official administrative boundary data. All data and scripts are embedded in this file; no network connection is needed.
